# Emmis Counting-Sort-Challenge

Implementiere den Sortieralgorithmus Counting Sort.

## Vorgegebene Methoden
```java
public int[] countValues(int[] values, int min, int max)
```
Ermittelt die Häufigkeiten der Werte zwischen `min` und `max`.
```java
public void sort(int[] values)
```
- Sortiert das Array mit Counting Sort aufsteigend.
- Negative Werte können ebenfalls vorkommen.
- Die vorgegebenen Methodensignaturen dürfen nicht verändert werden.
- Fertige Sortierfunktionen wie `Arrays.sort(...)` dürfen nicht verwendet werden.
